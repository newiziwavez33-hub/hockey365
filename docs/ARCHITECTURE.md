# Архитектура Hockey365

Статический хоккейный портал высокой информативности, оптимизированный для GitHub Pages.

---

## 1. Ключевые ограничения и принципы

* **Zero-Build & Zero-Node:** Никакого Node.js, Vite, Webpack, Parcel или Babel для публикации сайта. Браузер исполняет нативные ES-модули (`<script type="module">`). Папка `server/` является необязательным прокси для SSE и не участвует в static deploy.
* **Репозиторий = База Данных:** Все сущности сериализованы в компактные JSON-файлы в каталоге `/data`.
* **Серверные задачи делегированы GitHub Actions:** Сбор и нормализация данных выполняются Python-скриптами по cron или вручную через `workflow_dispatch`.
* **Автономия фронтенда (MPA + PWA):** Каждая страница имеет чистый URL (`/online/`, `/match/`, `/team/` и т.д.), использует общие компоненты и мгновенно кэшируется Service Worker.

---

## 2. Структура каталогов данных (`/data`)

```
data/
├── meta.json                         # Версия схемы, время обновления, статус
├── competitions.json                 # Правила лиг, структура конференций/дивизионов
├── teams/
│   └── {teamId}.json                 # Профиль команды, арена, список состава
├── players/
│   └── {playerId}.json               # Профиль игрока, сезоны, карьера
├── matches/
│   ├── by-date/
│   │   └── YYYY-MM-DD.json           # Матчи на дату (для ленты матчей дня)
│   └── {matchId}.json                # Полный boxscore матча (периоды, события, звенья)
├── standings/
│   └── {compId}-{season}.json        # Турнирные таблицы
├── playoffs/
│   └── {compId}-{season}.json        # Сетки плей-офф и серии
├── leaders/
│   └── {compId}-{season}.json        # Топ бомбардиров, снайперов, вратарей
├── news/
│   └── index.json                    # Лента новостей
├── transfers/
│   └── {season}.json                 # Таблица переходов и обменов
└── search-index.json                 # Индекс для мгновенного клиентского поиска
```

## 3. Слой ядра фронтенда (`assets/js/core/`)

1. **`config.js`** — Базовый путь (`BASE_PATH`), официальный NHL bridge, интервалы поллинга live-матчей (10 сек) и опциональный SSE URL.
2. **`api.js`** — Асинхронная загрузка JSON с кэшированием (Memory Cache + Cache API / IndexedDB) и обработкой сетевых ошибок.
3. **`store.js`** — Управление локальным состоянием (`localStorage`): избранные клубы/лиги, темы оформления (светлая/тёмная), выбранный часовой пояс, пользовательский API-ключ.
4. **`format.js`** — Форматирование дат и времени через `Intl.DateTimeFormat` с поддержкой часовых поясов (UTC, МСК, местное арены), форматирование счёта хоккея («ОТ», «Б»), процент отражённых бросков (0.925 -> 92.5%).
5. **`dom.js`** — Безопасный рендеринг элементов без уязвимостей XSS (экранирование спецсимволов, фабрика DOM узлов, управление классами).
6. **`i18n.js`** — Локализация интерфейса (русский язык по умолчанию, хоккейные термины).
7. **`router.js`** — Управление навигацией, обработка параметров URL (`?id=...`, `?season=...`, `?date=...`).

---

## 4. Контракт безопасности и CSP

* Все внешние данные валидируются через JSON Schema в CI перед публикацией.
* В HTML запрещён инлайн опасных скриптов без санитизации.
* Используется строгий Content Security Policy: стили и скрипты только локальные (self), изображения и SVG только локальные.
