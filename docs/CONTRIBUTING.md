# Руководство по разработке и поддержке Hockey365

## Локальный запуск проекта

Так как проект не использует Node.js и npm, запуск локального веб-сервера выполняется средствами Python:

```bash
# Из корня проекта:
python3 -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000`

---

## Запуск валидаторов и тестов

Все тесты и нормализаторы данных написаны на Python 3:

```bash
# Активация виртуального окружения
source .venv/bin/activate

# Валидация всех данных по JSON-схемам и бизнес-правилам
python3 tools/validate_data.py

# Сборка индекса поиска
python3 tools/build_search_index.py

# Генерация карты сайта и robots.txt
python3 tools/build_sitemap.py

# Запуск полного набора юнит- и e2e-тестов
pytest tests/
```

## Как добавить новую лигу

1. Добавьте запись лиги в `data/competitions.json` с указанием правила начисления очков (`pointsRule: "2-1-0-ot"` или `"3-2-1-0"`), структуры конференций и дивизионов.
2. Поместите векторную эмблему в `assets/logos/comp/{compId}.svg`.
3. Добавьте команды в `data/teams/`.
4. Запустите `tools/normalize.py` и `tools/validate_data.py`.

---

## Как внести данные вручную (для КХЛ / ВХЛ)

Внесите матчи, команды или переходы в каталог `data-manual/khl/` в формате JSON или CSV, после чего запустите:
```bash
python3 tools/normalize.py --source manual
```
Скрипт нормализует данные, пересчитает турнирную таблицу и обновит поисковый индекс.
