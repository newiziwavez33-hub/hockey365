О проекте Hockey365

Hockey365 — это независимый хоккейный портал, вдохновлённый классическим форматом Soccer365.ru и адаптированный под специфику хоккея с шайбой (КХЛ, НХЛ, ВХЛ, МХЛ).

Ключевая идея и технологии

Портал построен по принципу «Репозиторий = База Данных». Здесь нет Node.js, Vite, сборщиков, MySQL или сторонних серверных бэкендов. Вся клиентская логика исполняется непосредственно браузером на нативных ES-модулях JavaScript. Все данные хранятся в виде открытых статических JSON-файлов в репозитории GitHub и обновляются с помощью автоматических скриптов Python через GitHub Actions.

Источники данных и атрибуция

  • НХЛ (Национальная Хоккейная Лига): публичные открытые интерфейсы статистики NHL Web API (api-web.nhle.com).
  • КХЛ (Континентальная Хоккейная Лига): структурированные справочные датасеты спортивных сводок и нормализованные архивы регулярного чемпионата и плей-офф.
  • Графика и эмблемы: логотипы и товарные знаки хоккейных клубов принадлежат их соответствующим правообладателям и используются исключительно в информационных целях для идентификации спортивных команд.

Открытый исходный код
