# Hockey365 — Прогресс разработки

## Статус проекта: аудит выполнен, публикация полной достоверной версии заблокирована отсутствием источника КХЛ

### Стек и целевая архитектура (Трансформация в Live-портал 2.0)
- **Ограничение «без бэкенда» снято** в соответствии с результатами продуктового аудита от 04.10.2026.
- **Целевой стек:**
  - Бэкенд: PostgreSQL (Supabase / Neon), Redis (кэширование и Pub/Sub), Node.js / Hono API.
  - Реалтайм: SSE для оперативного счёта и телеметрии матчей, WebSocket для чата.
  - Фронтенд: SSR (Next.js / Astro) с сохранением дизайн-токенов Dark Ice Void (`#0B0E14`), чистыми URL и PWA.
  - Источники данных: NHL Web API (официальный поток), лицензированный провайдер КХЛ/ВХЛ/МХЛ, RSS новостей.
- **Генеральный план трансформации:** зафиксирован в [PLAN.md](PLAN.md).
